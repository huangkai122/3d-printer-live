## 修复 douyin-bridge 换房死循环 bug（douyin-bridge.mjs）

- 现象：昨晚 17:30 切换直播间后，`desktop-bridge.log` 每 3 秒刷一条「独立直播窗口未就绪」，到今早刷了 1.79 万条（日志 1.7MB）。
- 根因：`launch.py` 检测到 WebView2 直播窗口(:9224)时设 `PRINTER_CDP_PORT=9224` 锁定来源；窗口被关闭后，`findTarget` 只查 9224（找不到即 continue），`run()` 又因锁定模式禁止 `launchStandaloneChrome` 兜底 → 永久死循环，不回退 9223/9110/9222。
- 改动（douyin-bridge.mjs 三处）：
  1. `process.env.PRINTER_CDP_PORT` 锁定改为模块级 `cdpLockedPort`（可解除）；
  2. `findTarget` 锁定模式下无目标房间 tab 时，复用窗口内已有直播间 tab（run() 挂接后自动 Page.navigate 换房）；`run()` 发现锁定端口无响应 → 解除锁定 + 回退默认来源 + 自动弹自建 Chrome 窗口；
  3. reconnect 重试日志去重：同一错误 30 秒内只打一次。
- 验证：node --check 通过；全套 `node --test *.test.mjs` 53/53 通过。
- 运维：停掉旧 bridge 进程 PID 6996（node douyin-bridge.mjs 755840355442，纯空转）。未自动重启抓取（会弹浏览器窗口，留给 Eric 决定）。
- 待办：未提交改动含昨日 gift-speech/index 双语工作 + 本次 bridge 修复，等 Eric 确认后 commit。
